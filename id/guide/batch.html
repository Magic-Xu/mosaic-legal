Edit foto

Beberapa foto

Pilih 1–10 foto, edit satu per satu, lalu ekspor foto saat ini atau seluruh grup.

Cara menggunakan

Gunakan panah di bawah kanvas untuk berpindah foto. Dalam grup, gunakan + untuk menambah hingga total 10. Edit yang ada tetap tersimpan. Mengganti seluruh grup adalah tindakan terpisah.

Setiap foto memiliki penutup, tanda air teks, dan riwayatnya sendiri. Posisi penutup tidak disalin antar foto. Pilih foto saat ini atau semua di menu ekspor, lalu periksa setiap hasil.

Tombol tindakan gambar di kiri atas dapat menghapus edit foto saat ini atau keluar dari pengeditan seluruh grup. Menghapus edit tetap membuka foto; keluar meminta konfirmasi jika ada perubahan.
