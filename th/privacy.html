นโยบายความเป็นส่วนตัวของ SnapMosaic

วันที่มีผลบังคับใช้: 2026-09-03

SnapMosaic (แอป) เป็นเครื่องมือความเป็นส่วนตัวสำหรับรูปภาพและวิดีโอที่ประมวลผลสื่อบนอุปกรณ์ มีฟังก์ชันโมเสก เบลอ ปิดบัง มาร์กเกอร์ ลายน้ำข้อความที่ผู้ใช้เพิ่ม สติกเกอร์อีโมจิใบหน้า และการปิดบังใบหน้าในวิดีโออัตโนมัติ นโยบายนี้อธิบายการจัดการข้อมูล

1. ข้อมูลที่เราเข้าถึงหรือประมวลผล

ไม่ต้องสร้างบัญชี และเราไม่มีระบบบัญชีหรือพื้นที่เก็บข้อมูลคลาวด์ของเราเอง

  • รูปภาพและวิดีโอที่เลือกใน Android หรือแชร์จากแอปอื่นจะประมวลผลบนอุปกรณ์และไม่อัปโหลดไปยังเซิร์ฟเวอร์ของผู้พัฒนา
  • การแก้ไข ข้อความลายน้ำที่คุณป้อน และข้อมูลการตรวจจับ ติดตาม และปิดบัง ใช้ในเครื่องเพื่อสร้างผลลัพธ์ ข้อความจะอยู่เฉพาะเซสชันแก้ไขและรวมในไฟล์เมื่อคุณบันทึกหรือแชร์เท่านั้น
  • ภาษา การส่งออก การลบข้อมูลเมตา ค่าตัวแก้ไข สถานะ Pro เวลาหมดอายุของสิทธิ์ชั่วคราวที่ไม่มีลายน้ำแบรนด์ SnapMosaic และร่างวิดีโออาจเก็บในพื้นที่ส่วนตัวของแอป Google Play ประมวลผลการซื้อ เราไม่เก็บข้อมูลบัตร หมายเลขคำสั่งซื้อ หรือ purchase token
  • เมื่อเลือกรายงานปัญหา แอปจะสร้างไฟล์วินิจฉัยในเครื่องที่มี ID แบบสุ่ม เวลา เวอร์ชัน API ผู้ผลิต/รุ่น ภาษา แหล่งติดตั้ง หน้าจอ ประเภทสื่อ ขั้นตอน การดำเนินการ ผลลัพธ์ และบันทึกที่ลบข้อมูลละเอียดอ่อนแล้วสูงสุด 250 รายการ รายงานการชำระเงินอาจมีรหัส Google Play Billing, ID ผลิตภัณฑ์ จำนวนสถานะซื้อ และสถานะ Pro โดยประมาณ แต่ไม่รวมสื่อ URI พาธ ชื่อไฟล์ ข้อความที่ตรวจพบ/ป้อน บัญชี หรือข้อมูลชำระเงิน
  • SDK โฆษณา การวิเคราะห์ ข้อขัดข้อง หรือ ML บนอุปกรณ์อาจเก็บ IP ตัวระบุอุปกรณ์/โฆษณา การโต้ตอบ เหตุการณ์ใช้งาน ข้อขัดข้อง ข้อมูลวินิจฉัย การใช้ SDK และสถานะดาวน์โหลดโมเดลโดยอัตโนมัติ

2. สิทธิ์และวัตถุประสงค์

แอปอาจขอความสามารถต่อไปนี้เฉพาะเมื่อใช้ฟังก์ชันที่เกี่ยวข้อง

  • เข้าถึงรูปภาพ/สื่อเพื่อเลือกรูปภาพหรือวิดีโอ
  • เขียนสื่อเพื่อบันทึกผลลัพธ์ลงอัลบั้มของอุปกรณ์
  • แชร์ระบบเพื่อรับรูปที่คุณส่ง แชร์ผลลัพธ์ หรือส่งไฟล์วินิจฉัยให้แอปอื่น

ใช้สิทธิ์ตามคำขอเท่านั้น ไม่ใช้เก็บข้อมูลเบื้องหลัง

3. วิธีประมวลผลข้อมูล

  • การแก้ไขรูป วิดีโอ และการตรวจจับใบหน้า QR/บาร์โค้ด และข้อความละเอียดอ่อนด้วย Google ML Kit ทำบนอุปกรณ์
  • ผลลัพธ์บันทึกในคลังสื่อของอุปกรณ์ เราไม่ส่งรูปหรือวิดีโอออกไปหากคุณไม่สั่งแชร์
  • ไฟล์วินิจฉัยอยู่ในแคชและไม่ส่งอัตโนมัติ แอปจะเปิดอีเมลที่เตรียมไว้ หรือหน้าต่างแชร์ Android หากไม่มีอีเมล คุณตรวจสอบ เลือกผู้รับ หรือยกเลิกได้ และแอปผู้รับควบคุมสำเนาของตน
  • การสร้างไฟล์วินิจฉัยใหม่จะลบรายงานเก่าออกจากแคช
  • หากเปิดการเสริมความเป็นส่วนตัว แอปจะพยายามลบ EXIF, GPS และข้อมูลเมตาอื่นเมื่อบันทึกรูป

4. บริการของบุคคลที่สาม

แอปและเว็บไซต์กฎหมายนี้ใช้

  • Google AdMob/Mobile Ads สำหรับโฆษณา; Google Analytics for Firebase สำหรับสถิติรวม; Firebase Crashlytics สำหรับความเสถียร; Google ML Kit สำหรับตรวจจับในเครื่อง; Google Play Billing สำหรับราคา ซื้อ Pro ครั้งเดียวและกู้คืน; GitHub Pages สำหรับโฮสต์เว็บไซต์
  • Google หรือ GitHub อาจประมวลผล IP ข้อมูลอุปกรณ์/เบราว์เซอร์ ตัวระบุ การโต้ตอบ ตำแหน่งโดยประมาณจากเครือข่าย ข้อขัดข้อง ข้อมูลวินิจฉัย ตัวชี้วัด และสถานะโมเดลตามนโยบายของบริการ
  • ข้อมูลอาจใช้เพื่อโฆษณา วิเคราะห์ ป้องกันการฉ้อโกง ความปลอดภัย และการปฏิบัติตามข้อกำหนด หากจำเป็นอาจใช้ Google UMP จัดการความยินยอมโฆษณา

เราไม่ส่งรูป/วิดีโอที่เลือก เฟรมวิดีโอ พื้นที่ใบหน้า หรือผลลัพธ์ไปยัง AdMob, Play Billing, Analytics, Crashlytics หรือบริการ AI ระยะไกล

ข้อมูลความเป็นส่วนตัวของ Google: https://policies.google.com/privacy

การเปิดเผยข้อมูล Google Mobile Ads: https://developers.google.com/admob/android/privacy/play-data-disclosure

Google Analytics for Firebase: https://firebase.google.com/docs/analytics

Firebase Crashlytics: https://firebase.google.com/docs/crashlytics

การเปิดเผยข้อมูล Firebase Android: https://firebase.google.com/docs/android/play-data-disclosure

การเปิดเผยข้อมูล Google ML Kit: https://developers.google.com/ml-kit/android-data-disclosure

คำชี้แจงความเป็นส่วนตัวของ GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

5. ความปลอดภัย การเก็บ และการลบ

  • การตั้งค่า สิทธิ์ที่แคช และไฟล์ชั่วคราวอยู่ในพื้นที่ส่วนตัว ปิดการสำรองข้อมูล Android แล้ว SDK ของ Google ใช้การส่งข้อมูลแบบเข้ารหัสตามเอกสาร
  • การตั้งค่าและสถานะ Pro อยู่จนถูกเขียนทับ ล้างข้อมูล หรือถอนการติดตั้ง สิทธิ์รางวัลหมดตามเวลาที่แสดง ข้อความลายน้ำอยู่เฉพาะเซสชัน ผลลัพธ์ที่บันทึกอยู่จนคุณลบ
  • ร่างวิดีโอที่ยังไม่บันทึกจะลบเมื่อปิด/เปลี่ยนสื่อ ยกเลิก หรือล้มเหลว แคชเก่าถูกล้างเป็นระยะ และเก็บไฟล์วินิจฉัยล่าสุดเพียงไฟล์เดียว
  • หลังแชร์รายงาน ผู้รับควบคุมสำเนา ข้อมูล SDK เป็นไปตามนโยบายผู้ให้บริการ ไม่มีวิธีใดปลอดภัยอย่างสมบูรณ์

6. ผู้เยาว์

แอปมีไว้สำหรับผู้ใช้ทั่วไป หากคุณเป็นผู้เยาว์ โปรดใช้ภายใต้คำแนะนำของผู้ปกครอง

7. ตัวเลือกและสิทธิ์ของคุณ

  • คุณลบผลลัพธ์และข้อมูลในเครื่อง ถอนการติดตั้งแอป และถอนสิทธิ์สื่อใน Android ได้
  • คุณรีเซ็ตหรือลบ ID โฆษณาได้หาก Android รองรับ
  • หากมีแบบฟอร์มความยินยอม คุณเปลี่ยนตัวเลือกในแอปหรือแบบฟอร์ม Google ได้
  • คุณดูการซื้อ ขอคืนเงินที่เข้าเกณฑ์ใน Google Play และกู้คืนการซื้อของบัญชีปัจจุบันได้
  • คุณติดต่อเราเรื่องความเป็นส่วนตัวได้ เนื่องจากเราไม่มีบัญชีหรือคลาวด์เอง โดยทั่วไปเราไม่สามารถระบุหรือลบข้อมูลที่อยู่บนอุปกรณ์ของคุณเท่านั้น ข้อมูลบุคคลที่สามเป็นไปตามขั้นตอนของผู้ให้บริการ

8. การปรับปรุงนโยบาย

เราอาจปรับปรุงนโยบายและวันที่เมื่อแอปเปลี่ยนแปลง เวอร์ชันใหม่จะเผยแพร่ที่นี่ และจะแจ้งการเปลี่ยนแปลงสำคัญในแอปหรือร้านค้าเมื่อกฎหมายหรือแพลตฟอร์มกำหนด
