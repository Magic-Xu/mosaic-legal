Detección inteligente

Cómo usarlo

Espera a que cargue la foto. Si el ocultado automático está activado, revisa las zonas cubiertas. Si no, pulsa «Inteligente» abajo para aplicar las sugerencias a caras, códigos y texto sensible habitual.

La detección puede omitir detalles. Una zona con contorno es solo una sugerencia; tócala para cubrirla. Si la detección no está disponible, oculta manualmente o abre su ayuda desde el signo de interrogación.

Ocultado automático y zonas individuales

En Ajustes puedes activar o desactivar el ocultado automático al abrir fotos. Está activado de forma predeterminada si no has guardado una preferencia. El cambio solo afecta a las fotos que abras después, no a la foto actual.

Para cambiar el efecto de una zona detectada, elige un efecto y toca la zona. Si ya tiene el efecto seleccionado, tocarla elimina su cobertura. Revisa el resultado después de cada cambio.

El reconocimiento de texto sigue el idioma de la app. No está disponible para tailandés ni urdu; caras y códigos funcionan por separado. Cambia el idioma en Ajustes. Los efectos y ajustes de herramientas se recuerdan para nuevas fotos.
