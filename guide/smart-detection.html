Smart detection

How to use it

Wait for the photo to load. If automatic masking is enabled, review the applied masks. Otherwise, tap “Smart” at the bottom to apply suggested masks to faces, codes, and common sensitive text.

Detection can miss details. An outlined area is only a suggestion; tap it to cover it. If detection is unavailable, use manual masking or open detection help from the question-mark menu.

Automatic masking and individual areas

In Settings, turn “Auto-mask new photos” on or off. It is on by default if you have not saved a preference. Changing it affects newly loaded photos; it does not change the photo already open.

To change a detected area's effect, select an effect and tap the area. If that area already uses the selected effect, tapping it removes its mask. Check the result after each change.

Text recognition follows the app language. Thai and Urdu text recognition are currently unavailable; face and code detection work independently. Change the app language in Settings. Tool effects and adjustments are remembered for later photos.
