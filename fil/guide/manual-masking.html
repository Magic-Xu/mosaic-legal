Halimbawa ng pagpili ng salita

Piliin ang mga bahaging itatago

I-tap ang bahagi ng numero para takpan o ipakita. Subukang iwan na nakikita ang una at huling mga digit.

Mga bahaging natakpan 1 / 3

Paano gamitin

Pindutin nang matagal ang natukoy na linya ng teksto, saka piliin ang mga salita o bahaging itatago. Para sa nakaligtaan, buksan ang pantakip na tool, pumili ng effect, at piliin ang parihaba o brush sa “Ayusin”. Gamitin ang I-undo kapag nagkamali.

Para sa sensitibong teksto, gumamit ng solidong kulay na may 100% opacity at takpan ang buong detalye. Pang-highlight lang ang marker; nababasa pa rin ang nasa ilalim nito.

Ayusin ang parihaba

Pagkatapos gumuhit ng parihaba, i-drag ang mga handle sa sulok para baguhin ang laki. I-tap ang parihaba para tapusin ang pag-aayos at panatilihin ang takip. I-tap muli para alisin ito. Mawawala ang mga handle ng naunang parihaba kapag gumuhit ka ng bago.

Gamitin ang Undo at Redo para itama ang mga pagbabago. Mag-zoom in para suriin ang mga gilid at tiyaking natatakpan ang buong detalye.

Mga effect at kulay

I-tap ang Takpan o Marker para piliin ang tool. I-tap muli ang napiling tool para buksan ang mga control. Pumili ng mosaic, blur o solid block; nasa Adjust ang rectangle o brush mode, laki, at lakas ng mosaic o blur.

Para sa solid block o marker, buksan ang rainbow palette upang baguhin ang kulay at opacity. Gamitin ang grid, spectrum, RGB o Hex. Maaari mong i-drag ang palette button sa ibang gilid ng canvas. Magkahiwalay na naaalala ang mga setting ng masking at marker.
