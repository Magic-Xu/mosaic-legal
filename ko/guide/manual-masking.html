사용 방법

인식된 텍스트 줄을 길게 누르고 가릴 단어나 부분을 선택하세요. 빠진 부분은 가리기 도구에서 효과를 고른 뒤 “조정”에서 사각형이나 브러시를 선택해 직접 가리세요. 잘못 편집했다면 실행 취소를 사용하세요.

민감한 텍스트는 불투명도 100%의 단색 블록으로 완전히 가리세요. 형광펜은 강조용이므로 밑의 내용을 여전히 읽을 수 있습니다.

사각형 범위 조절

사각형을 그린 뒤 모서리 핸들을 드래그해 크기를 조절하세요. 사각형을 누르면 조절이 끝나고 가리기는 유지됩니다. 한 번 더 누르면 삭제됩니다. 새 사각형을 그리면 이전 사각형의 핸들은 숨겨집니다.

실수한 경우 실행 취소와 다시 실행을 사용하세요. 사진을 확대해 가장자리를 확인하고 숨길 내용 전체가 가려졌는지 살펴보세요.

효과와 색상

가리기 또는 형광펜을 눌러 도구를 선택하고, 선택된 도구를 다시 누르면 설정이 열립니다. 모자이크, 흐림 또는 단색을 선택하세요. 조절에서 사각형이나 브러시, 크기, 모자이크 또는 흐림 강도를 설정할 수 있습니다.

단색이나 형광펜을 선택한 뒤 무지개 팔레트에서 색상과 불투명도를 조절하세요. 격자, 스펙트럼, RGB, Hex 입력을 지원합니다. 팔레트 버튼은 캔버스의 다른 가장자리로 끌 수 있습니다. 가리기와 형광펜 설정은 따로 기억됩니다.
