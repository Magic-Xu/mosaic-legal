개인정보 처리 방식

기능

작은 디테일까지, 내 방식대로.

01 / 05

선택한 부분만 가리세요.

감지된 글줄을 길게 누르세요. 가릴 글자만 선택하고 나머지 내용은 읽기 쉽게 남겨두세요.

02 / 05

얼굴은 가리고, 즐거움은 그대로.

감지된 얼굴을 이모지 스티커로 가리세요. 얼굴마다 다른 표정을 골라 단체 사진의 분위기를 살릴 수 있습니다.

03 / 05

영역마다 다른 효과

모자이크, 블러, 단색 가리기를 선택하세요. 브러시와 도형, 효과 조정, 확대, 실행 취소와 다시 실행을 지원합니다. 형광펜으로 중요한 부분을 강조할 수도 있습니다.

04 / 05

나만의 텍스트 워터마크

반복되는 텍스트 워터마크로 이미지의 용도를 표시하세요. 문구, 색상, 불투명도, 크기, 각도, 간격을 조정할 수 있습니다.

05 / 05

저장과 공유 설정

JPEG, PNG, WebP와 출력 크기를 선택하고 새 이미지로 저장하거나 Android를 통해 공유하세요. 내보낼 때 EXIF와 GPS 메타데이터를 제거하여 공유 파일에 위치정보가 포함되지 않도록 할 수 있습니다.

자주 묻는 질문

알아두면 좋은 내용.

지원 문의
SnapMosaic은 무료인가요?

사진 편집 도구는 무료로 사용할 수 있으며, 무료로 내보낸 사진에는 기본적으로 SnapMosaic 브랜드 워터마크가 포함됩니다. 선택 사항인 Pro를 한 번 구매하면 브랜드 워터마크와 앱 내 광고가 제거됩니다.

편집할 때 사진이 업로드되나요?

계정이 필요하지 않습니다. 선택한 사진은 기기에서 처리되며 편집을 위해 SnapMosaic 서버에 업로드되지 않습니다. 광고, 구매 및 관련 서비스는 네트워크를 사용할 수 있습니다. 자세한 내용은 개인정보처리방침을 확인하세요.

Pro 구매를 어떻게 복원하나요?

구매할 때 사용한 Google Play 계정으로 로그인하세요. SnapMosaic 설정에서 Pro 페이지를 열고 구매 복원을 선택하세요. 유효한 구매가 확인되면 SnapMosaic 브랜드 워터마크와 앱 내 광고가 제거됩니다.

준비되면 공유하세요.
